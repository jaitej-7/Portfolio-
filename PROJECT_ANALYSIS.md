## 🏗️ Core Architecture: The Infinite Canvas

Unlike traditional portfolios that use vertical scrolling, this project implements a **2D Infinite Canvas**. 

### How it Works
1. **Coordinate System:** Every major section (`Hero`, `About`, `Work`, etc.) is placed at specific X and Y coordinates on a virtual plane.
2. **Smooth Panning:** When a user navigates, the entire canvas translates to the negative coordinates of the target section, centering it in the viewport.
3. **Zooming Layer:** A nested transformation layer allows the user to scale the entire view, providing a "bird's-eye view" of the portfolio.
4. **Transition Physics:** Uses a custom cubic-bezier transition (`0.16, 1, 0.3, 1`) for a 1-second duration, giving it a high-end, responsive feel.

- **Pan/Zoom Logic:** Two-tier `div` structure (one for scale, one for translation).
